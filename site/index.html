Owen Vault Sync

A private, single-user utility that synchronizes a local Obsidian mobile vault with one folder in the owner's Google Drive.

The app requests only the drive.file scope. It can access files and folders created or explicitly opened by this app; it cannot browse unrelated Drive content.

OAuth credentials and sync state are stored locally on the owner's devices. No separate application server receives vault files or Google tokens.
